# Useful Core — post-analysis questions

Appended 2026-11-12 HKT after the single frozen D2 analysis. These are post hoc questions, not pre-registered claims or permission to rerun collection. They belong in `collection/delivery/` because a new root file would invalidate the frozen source inventory. Original QUESTIONS.md is preserved.

1. **Can an instruction make claims sound more modest without making them truer?** Qwen 7B’s outage false-full claims fell from 62/100 to 2/100 with fallback framing, yet accuracy and utility stayed zero. Across all worlds fallback yielded 102 reduced-tier reports with no deliveries. A new version could separate claim vocabulary from receipt-grounded reporting with matched prompts and an independently frozen truth check.
2. **Why does a technically valid agent repeatedly read a resource it already has?** Qwen 7B completed 285/300 episodes technically but delivered nothing; a calm seed-0 full trace reads six times. Is the bottleneck state tracking, copying opaque references, action selection, or an ambiguous finish contract? An explicitly controlled interface experiment would be needed; this run does not isolate a cause.
3. **Does making JSON schema-constrained change the scientific question enough to unlock the floor?** Qwen 1.5B failed its first reference field in 300/300 episodes under frozen JSON mode. Test a separately frozen schema/receipt interface against that preserved baseline, rather than interpreting the floor as planning inability or silently repairing this run.
4. **Why does fallback guidance increase failed-tool repetition in Qwen 7B?** Its outage repeat rate was 0.47 per episode versus zero under full framing, even though neither arm delivered. Does it explore farther into the dependency chain without learning to commit the cached core? More exploration is not evidence of better recovery.
5. **How much apparent prompt benefit can two network losses create?** Claude’s all-scheduled outage ΔY was +0.00833, but its nine complete outage blocks had ΔY=0. How should a future protocol report reliability and behaviour separately while preserving the operational endpoint and avoiding outcome-selected retries?
6. **Can an agent match a receipt-only script while wasting its last safe delivery chance?** Claude reached the maximum in 58/60 episodes yet repeated failed tools 71 times; the frozen highest-feasible script reaches all three ceilings without hidden health. A new study could vary action quota and price to test recovery efficiency, without claiming this task identifies a general architecture advantage.
7. **What minimum task diversity would make a zero interval informative?** Every local contrast has [0,0], but 50 seeds repeat three dependency structures and shared local sampling seeds. A future version needs varied graphs and reference presentation, with task families as the resampling units, before generalizing a framing null.
