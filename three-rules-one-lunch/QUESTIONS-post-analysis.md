# Three Rules, One Lunch — post-analysis questions

Append-only exploratory questions, not registered findings or approval for more collection. Earlier v0.1 questions remain in [build/delivery/QUESTIONS-post-analysis.md](build/delivery/QUESTIONS-post-analysis.md).

## 12 November 2026 HKT — v0.2, Codex for Claude’s delegated review

All questions below are **post hoc**. They preserve the failed primary, original code controls, v0.1 evidence and the stop after v0.2; no extra run or new inferential test is proposed as part of this delivery.

1. **Did the interface failure turn into an abstention problem?** Every local v0.2 episode is valid, yet Qwen 7B shared workers skip 82.0% of opportunities and earn only 16.2% of greedy-shared reward. What would distinguish uncertainty about the action contract from an intentional search policy? The version comparison is descriptive, and schema validity alone cannot identify why nulls were chosen.

2. **Why does the smaller model act more usefully?** Qwen 1.5B shared Y=0.196021 exceeds Qwen 7B’s 0.053749 and Llama 8B’s 0.087218, while its null rate is 38.1%, versus 82.0% and 70.7%. Does the ranking reflect action propensity, receipt use, or something else? A registered comparison would need to separate these possibilities without filtering out abstentions after the fact.

3. **Is the measured sharing gain largely ordinary greedy reuse?** Llama’s gain is 0.020562 Y and Qwen 1.5B’s 0.019900, close to the simple script’s 0.020583; all local regimes remain below random’s overall reward. What evidence would show value beyond that code policy, and would a phase-aware control remove the apparent model advantage over stale greedies after relocation? No difference-of-gains test was registered here.

4. **What does an improved reward estimate miss about productive harvest?** Qwen 7B ΔY has a positive interval, while ΔH’s interval crosses zero, so P1 fails its joint rule despite complete technical evidence. Which search trajectories raise small rewards without reliably creating ≥500 harvests? Such a breakdown would be exploratory and cannot change the threshold or rescue the primary.

5. **Can a model avoid old peaks without adapting at all?** Qwen 7B workers never query true old peaks after relocation, yet shared post-Y is only 0.011347. Meanwhile Qwen 1.5B shared workers revisit their best observed old cells 2.97 times per episode versus 2.03 private and still earn more after relocation. Which behavior measure would distinguish useful reuse, exploration, abstention and obsolete exploitation? The current stale metrics describe target sets, not intent or causation.

6. **Why pay for three workers if one central call earns more?** Each local central regime earns more than shared workers using 400 versus 1,200 calls, but quota, history length and token use also change. What would an explicitly compute-matched design show? Claude’s descriptive ranking points the other way and includes three retained central operational failures, so neither pattern establishes an architecture-wide rule.

7. **How much of Claude’s script advantage survives a stronger adaptive script?** Claude shared Y=0.465675 is 143.7% of greedy-shared; its post-Y is 0.444542 versus the script’s 0.183300. The greedy never resets stale receipts, and the twenty-seed sharing interval includes zero. Would a predeclared phase-aware code policy account for much of the gap before invoking reasoning or cooperation?

8. **How should later studies present known outcomes in repeated prediction lists?** P6 was already observed to hold and P7 already known to fail from retained Claude central validity. What reporting makes these inherited facts visible without suggesting independent prospective confirmation? This report keeps both statuses and their provenance; neither contributes new evidence from v0.2.
